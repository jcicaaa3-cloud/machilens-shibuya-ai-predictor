# Data Card — Synthetic MachiLens Sample Data

The included sample data is synthetic. It is generated to test and explain the AI pipeline, not to represent verified Shibuya statistics.

## Why synthetic data

Some urban indicators that would be useful for this type of project can be private, restricted, copyrighted, expensive, or difficult to validate. The public portfolio version therefore uses generated sample data so the code and demo can be shared safely.

## Included fields

- normalized pedestrian-flow signal
- normalized vacancy signal
- normalized tourism signal
- normalized K-culture / SNS proxy signal
- normalized hotel-occupancy proxy signal
- scenario flags for A/B/C
- policy sliders for night economy, K-culture activation, and public/private support

## Data rights note

No external maps, logos, paid report tables, raw card-company data, telecom mobility data, or third-party images are bundled in the public package.
