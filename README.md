# MachiLens

[日本語](README_JA.md) · [한국어](README_KO.md)

A small model for comparing urban strategy scenarios for Shibuya, trained on synthetic data.

The idea came from a university class on the redevelopment of Shibuya. Back then it ended as a planning report with nothing that actually ran. This repository is the rebuild: a synthetic data generator, a PyTorch model, a prediction script, and a browser demo.

It does not forecast the real Shibuya. All data here is generated by code, and the outputs should not be used for policy, investment, or real-estate decisions.

Demo: https://jcicaaa3-cloud.github.io/machilens-shibuya-ai-predictor/

## Scenarios

| Scenario | Meaning |
| --- | --- |
| A | Minimal intervention |
| B | K-culture and night economy |
| C | Local community |

Inputs are the scenario plus three sliders (night economy, K-pop fandom, policy support). Outputs are a success probability, the change in pedestrian flow, the change in vacancy rate, and a risk score.

## Model

- BiLSTM with temporal attention over a 24-step window of 5 city indicators
- An MLP that merges the sequence encoding with a 6-dimensional scenario/policy vector
- Three heads: success classification, scenario classification, and regression for flow and vacancy change
- MC dropout (16 samples) for an output range

Code is in `src/machilens_ai/`.

## Results

From the bundled demo run (700 synthetic samples, 3 epochs). Files: `reports/demo_metrics.json`, `reports/baseline_metrics.json`.

| Model | Success accuracy | Brier | Flow MAE | Vacancy MAE |
| --- | ---: | ---: | ---: | ---: |
| BiLSTM + attention | 0.60 | 0.248 | 0.020 | 0.043 |
| Random forest baseline | 0.85 | 0.117 | 0.017 | 0.010 |

The random forest baseline is better than the neural model on every metric in this run.

## About the demo numbers

The values in the browser demo and in `reports/prediction_*.json` are not raw network outputs. `predict.py` replaces them with per-scenario preset values adjusted linearly by the sliders (`calibrate_demo_output`), and the browser demo uses the same formula in JavaScript without running a model. The raw network output is kept in the `raw_model_output` field of each prediction file.

## Run

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

PYTHONPATH=src pytest
PYTHONPATH=src python -m machilens_ai.train --epochs 3 --n-samples 900
PYTHONPATH=src python -m machilens_ai.predict --scenario B --night-economy 0.82 --kpop-fandom 0.86 --policy-support 0.74
streamlit run app/streamlit_app.py   # optional
```

## Limitations

- The data is synthetic. Results depend on the assumptions built into the generator.
- No block-level geography; the city is five aggregate indicators.
- A real version would need verified data and validation against what actually happened.
