I rebuilt an unfinished urban analytics idea into a portfolio-ready AI demo:

**MachiLens AI — Shibuya Scenario Forecast Lab**

MachiLens AI compares Shibuya urban strategy scenarios using synthetic urban time-series data, policy sliders, and a PyTorch-based model pipeline.

The project includes:

- synthetic urban data generator
- BiLSTM + attention model
- multi-task prediction heads
- baseline comparison
- browser-ready HTML demo
- Streamlit dashboard option
- model and data notes

The main lesson: not every AI project needs to pretend it can perfectly predict the future. Sometimes the stronger work is turning a vague strategy question into a transparent, testable, and easy-to-review simulation workflow.
